# Portfólio de Testes de Software

Este repositório contém exemplos de projetos e habilidades aplicadas na área de **testes de software**. Aqui você encontrará documentos de **análise de requisitos**, **casos de testes**, **testes manuais**.

## Estrutura

- **/analise-requisitos**: Exemplos de análise de requisitos para diferentes tipos de software.
- **/casos-de-teste**: Exemplos de casos de teste estruturados.

## Ferramentas que podem ser usadas para análise de requisitos

Jira (para tracking de requisitos)

Confluence (para documentação de requisitos)

MindMap (para brainstorming e visualização)
